Версия от 03.11.2026 в стиле обложки химического канала: чёрный фон,
розовые и голубые мазки, тёплый рисованный портрет и тёмные дашборды.
Обложка заменена на изображение, выбранное владельцем 03.11.2026.
Опубликованный сайт: https://alexander-bortulev-portfolio.ribbedlarch2.chatgpt.site

Зависимости устанавливаются командой ниже, сборка создаётся из исходников.

КАК ЗАПУСТИТЬ ЛОКАЛЬНО
1. Распакуйте архив.
2. Нужны Node.js версии не ниже 22.13.0 и pnpm 11.25.0
   (версия pnpm зафиксирована в package.json).
3. Откройте терминал в папке bortulev-portfolio, где лежит package.json.
4. Установите зависимости:

   pnpm install --frozen-lockfile

5. Соберите сайт:

   pnpm build

6. Для работы формы создайте локальные таблицы базы данных. На новой
   локальной базе выполните следующую команду один раз одной строкой:

   node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_nervous_prism.sql

7. Запустите собранный сайт:

   pnpm start

8. Откройте адрес, который появится в терминале.
   Для разработки вместо шага 7 можно использовать pnpm dev.

Просто открыть index.html двойным щелчком недостаточно: этот проект
использует серверные маршруты, а форма — серверный обработчик и D1.
Запускайте его командами выше.

О ФОРМЕ И БАЗЕ ДАННЫХ
Форма сохраняет имя, email, необязательный вопрос и отметку согласия.
Обработчик: app/api/registrations/route.ts.
Таблица: registrations. Уведомления по электронной почте не подключены.
В архив входит структура базы; заявки с опубликованного сайта в этот
экспорт исходников не входят. Локальная и опубликованная базы раздельны.

ПЕРЕНОС НА ДРУГОЙ ХОСТИНГ
Для полного функционала нужен хостинг, поддерживающий серверную часть
проекта и базу D1. GitHub Pages обслуживает только статические файлы,
поэтому текущую форму с сохранением заявок там нельзя запустить без
отдельного сервера и соответствующей адаптации.

Исходники этого экспорта соответствуют опубликованной версии сайта.
Проверка сохранения исходного текста: node scripts/check-content.mjs
